# DL3 Investment Intelligence

**Live site (sample data only):** https://dl3-project-1.onrender.com/

A web app that shows how DL3 could compare LIHTC opportunities by state and local area: an overview, a ranking map and list, a page for each territory, and the public sources behind the numbers.

## What works now

- **Overview:** headline numbers and the top-ranked areas.
- **Rankings:** a map of the states (zoom with a trackpad pinch or Ctrl + scroll, drag to move when zoomed in) or a list, sortable by type.
- **Territories:** one page per state or local area, with its details.
- **Sources & Evidence:** the public source register from the DL3 guide.

## What's coming later

- AI Review, Ranking History, Review Queue and Settings.

## Important

- All numbers and territory names are **made-up sample data**. Rule values say "Needs verification" until a reviewer confirms them.
- Private DL3 data is not in this repository and must never be committed here.

## Run it on your computer

```bash
npm install
npm run dev
```

Then open the address it prints, usually http://localhost:5173.
